# 压力单帧：集中双焦点对比

## 1. 问题与范围

用户确认35 mm间距、50 mm高度仍感觉保鲜膜中间一整块下凹，希望两个区域更清楚、强度更高。本次只更新上位机离线相位计算，不改变供电、载波、驱动等级、校准或板端协议。保鲜膜形变原因尚未测量，不能从模拟判断硬件、相位校准或膜的机械响应是否正常。

## 2. 新增生成方式

压力窗口默认“**双点增强（集中能量）**”，可切回“区域还原（原算法）”。新方式将最多两个主要接触区域收紧为它们的中心焦点，保留中心位置、指定间距和基于源区域压力积分的相对权重；**放弃原区域大小、轮廓和朝向的复现**。单区域时生成单焦点。

默认高度50 mm、中心间距35 mm、源映射范围40 mm、等级100、调制0。改变模式/参数立即作废旧生成结果，必须重新生成后再发送；不会自动写设备或启动。原始三维回放和源压力数据不改。

## 3. 相位求解

- 仍使用64路等幅声源，仅调整相位，最终量化为64级。校准补偿仍由板端加一次。
- 原算法拟合较宽的高斯幅值分布；新算法只拟合主要区域中心的声压幅值，期望值为`0.65 * sqrt(区域压力积分 / 最大区域压力积分)`，相对理想中心单焦点归一化。0.65是求解目标，不是硬件等级，也不是保证实测幅值。
- 保留原幅值误差与背景平均/峰值惩罚；在至少x/y各±80 mm的平面上，以2 mm网格约束距离所有目标中心均不小于8 mm的背景，包含预览窗外的杂散峰。
- 四个均匀相对焦点相位初值，最多300次迭代；保留损失最小的连续相位解，再量化、重新计算结果。没有把通道分成两半。
- 目标图是焦点位置示意（3.5 mm宽度参数的高斯标记），不是实际焦斑尺寸保证，也不是新算法逐像素拟合的目标。界面明确显示“目标焦点示意”；不把与此示意图的均方根误差当作优化质量指标。

这仍是各向同性简化声场模型，未模拟膜形变、反射或真实声源方向性；8 mm背景豁免半径是本轮50 mm实验的设计参数，不代表所有高度/阵列都有同样分辨率。

## 4. 同条件对比

内置第325帧，8×8、10.3 mm阵元间距、高度50 mm、中心间距35 mm。相位均先量化为64级，再独立计算声场。以下均为相对声压幅值，不是绝对声压或实测形变：

| 指标 | 原宽区域算法 | 双点增强 |
| --- | ---: | ---: |
| 第一个目标中心 | 0.4397 | 0.6385 |
| 第二个目标中心 | 0.3859 | 0.6379 |
| 两中心连线中段20%内最高值 | 0.0695 | 0.0226 |
| 连线正中点 | 0.0435 | 0.0030 |
| x/y各±80 mm、距两中心均≥8 mm的背景最高值 | 0.3288 | 0.2678 |

两个中心分别增加约45%和65%，更均衡。最后一行采用两种算法**相同背景掩膜**、1 mm网格；不能直接比较各自默认目标阈值定义的`background_peak`，因为目标形状不同。此背景峰值下降也不意味着每个位置都下降。

另外试过仅把原宽区域算法目标峰值由0.5增至0.7/0.9，目标中心只小幅改善，远不及集中焦点；集中焦点目标增至0.8/1.0仅少量增益且背景更高，故默认选择0.65。初步探索记录在`.runtime/pressure-focus/comparison*.json`，最终生产实现的复现结果为`focus-comparison.json`。

## 5. 模型敏感性与限制

将同一组相位在45 mm和55 mm平面重新计算，两目标中心均仍强于旧算法，但不同位置增益不同，不能要求偏离设计平面后保留相同提升。假设半径5 mm的均匀圆活塞方向性进行敏感性计算，也保留提升；这不是实测换能器方向图，未替换生产模型。

原算法在理想模型中已存在两峰和中间低谷；因此用户看到的一整块凹陷，不能仅通过增加求解强度解释或保证消除。新方式的代价是失去区域形状。若同条件实物仍只有一块，下一步应在两个目标中心及中间点做接收幅值对照，确认声场是否真正分开，再判断膜的响应；不要继续仅凭图像扩大间距或提高数值。

## 6. 复现与验证

```powershell
python -m experiments.pressure_focus_compare
python -m unittest desktop_app.tests.test_pressure -v
```

比较脚本完全离线，输出同一色标对比图、连线曲线及数值到`.runtime/pressure-focus/`。专项测试覆盖设计点强度、平面外/方向性敏感性、共同背景范围、单区域/不等权区域、原算法保留、相位量化、协议回读和非均匀补偿只加一次。界面检查使用模拟设备并禁止打开真实串口/蓝牙，核验模式切换作废旧结果、不自动发送、底部可见及发送不启动。

本次结果：9项压力专项测试通过；200%缩放源程序界面检查、100%缩放打包版压力流程自检通过。图像/数值在`focus-comparison.*`，界面记录在`ui-200/`和`frozen/`。没有进行真实发射或接收测量。

## 7. 操作

在新版“三维回放”选第325帧，打开“发送当前帧压力”，确认“生成方式”为“双点增强（集中能量）”，高度50、间距35、等级100、调制0。停止设备后重新生成并发送，等待该帧回读确认，再进入播放控制单独播放。模式切回“区域还原（原算法）”可同条件对照。无需重烧或重做校准。

## 8. 构建

新版独立目录`desktop_app/dist/pressure-focus/`，构建日志和检查结果在`.runtime/pressure-focus/`，不覆盖此前间距版。实际打开/发送状态须以交接最新记录为准；构建或模拟自检不代表新相位已经上传到真实设备。

## 9. 研究参考

[Phase Optimization for Multipoint Haptic Feedback Based on Ultrasound Array（Sensors, 2022）](https://www.mdpi.com/1424-8220/22/6/2394)讨论了多焦点相位控制和等幅换能器约束，并以液面形变验证其平台。本次实现沿用本仓库幅值损失，改为中心目标加背景惩罚，**没有复现该论文的伪逆算法，也不把论文实验效果当成本项目结果**。
