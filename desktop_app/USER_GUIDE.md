# 触见体验台使用说明

完整解压后双击 `触见体验台.exe`，保留旁边的 `_internal` 文件夹。无需安装 Python，首次打开请稍等片刻。

## 开始使用

1. 打开左侧“连接设备”。USB 串口连接需要选择设备端口和匹配的波特率；波特率支持手动输入。蓝牙连接先查找设备，再选择配套模块。连接成功后不会自动开始呈现。
2. 在“图形库”选择图案，或在“自由创作”中绘制自己的轮廓。也可以打开以前保存的图形。
3. 点击“呈现此图形”或绘图区下方的“呈现图形”。程序会弹出确认窗口，在这里查看手掌预览、调整大小、呈现距离及重复速度。呈现距离为发射面到掌面的实际距离。“调整图形位置”可修改水平和前后位置。
4. 点击“确认并开始”。程序发送图形，等待设备确认后自动开始；如果正在呈现其他图形，会先停止再替换。成功后才出现“当前呈现”入口，可暂停、继续或停止。

如果尚未连接，在确认窗口点击“连接设备并继续”。连接成功后会返回确认窗口，再点击“确认并开始”。连接本身不会启动输出。点击“返回修改”只关闭确认窗口。

没有硬件时，在连接方式中选择“无设备演示”。演示模拟同一套发送与设备反馈流程，不产生实际触觉。演示不会自动播放。

顶部“连接设备”可直接使用当前设置连接，缺少串口参数时弹出设置窗口；连接后变为“断开连接”，连接过程中可以取消。左侧连接页用于更换连接方式和参数。

## 绘制与保存

- 选择直线、矩形、圆或曲线工具，在画布上绘制。双击可选择整个轮廓；拖动旋转手柄可以旋转。
- 左侧“尺寸”设置长度、半径、旋转或缩放；右侧“几何关系”设置重合、水平、竖直、平行、垂直、相切。不适用的关系无法点击，指向按钮可查看原因。
- 已设尺寸和几何关系分别列出，选中后可以移除。“呈现顺序…”用于调整各轮廓的先后顺序。
- 呈现前的确认窗口显示图形与手掌的相对位置。手掌仅为位置示意，不会检测或跟踪手部。
- `Ctrl+S` 保存图形，`Ctrl+O` 打开图形。保存文件同时保留草图及呈现路径；最近打开或保存的文件会显示在“图形库”。

## 设备状态

只有在图形发送成功并得到匹配反馈后才会开始呈现。修改后重新点击“呈现图形”并确认即可。停止操作会取消尚未完成的呈现请求，不会在延迟反馈到达后再次启动。

呈现画面的亮点依据设备返回的位置更新。连接中断时不再显示当前位置，需要恢复连接后操作。演示模式会明确标注。

使用设备板载按键时，可在“连接设备”页面选择“使用设备按键”；回到电脑操作时选择“使用电脑控制”。

## 声场演示

- “理论声场”计算阵列声波叠加，可选择待发图形或设备回读；它是预测，不是测量。
- 测绘前点击“准备测绘焦点…”，确认距离并启动固定焦点；程序会提醒保存未保存的草图。接收器位置由人工填写，每个测点保存三个原始采样窗口，并显示单点波形。
- 在同一 z 平面采集至少三个不共线的位置后，可开启“测点间线性插值”。圆点为采样位置，底色为测点之间的估计，包围区域外留空；一条线上的测点无法生成二维插值图。
- “理论 / 实测对比”共用测点坐标及归一化参考点。CSV 可导出、导入原始采样和测点位置。Demo 合成数据会明确标注；实际记录为接收端电压，尚未标定为声压。

## 三维回放与压力单帧

“三维回放”内置手部动作与接触压力样本，可播放、逐帧、拖动时间轴及调整速度。左键旋转、右键平移、滚轮缩放；离开页面自动暂停。回放不控制设备输出，数据来自外部数据集，不是手部实时跟踪。

选择一帧并点击“发送当前帧压力…”，生成后查看原始压力、简化目标与模拟声场。可调整呈现距离和接触范围；改变参数后须重新生成。连接支持静态相位的设备或模拟设备，点击“发送此帧（不启动）”，收到完整确认后通过“查看播放控制”进入当前呈现，再主动开始。

压力单帧没有移动焦点，画面不会显示虚构的轨迹亮点。普通绘图草稿保持不变，重新确认并呈现普通图形即可退出静态压力模式。数据及衍生标注的许可说明随程序一起提供。

默认勾选“保持整段动作的位置与大小”，使各帧沿用同一坐标映射，保留接触区域在动作中的移动。取消勾选适合单独查看一帧，不能据此比较帧间位移。“导出手姿与压力分析…”保存整段的关节特征、有效标记及压力中心；“导出动作相位计划…”均匀选取最多12帧，保存每帧的64路相位及生成指标，供离线复查，不自动发送或连续播放。

“导入序列”支持 EgoPressure 的 NPZ／Parquet，以及 ContactPose 的单个 `annotations.json`。后者仅含抓握关节，导入双手标注时需选择左手或右手；没有压力时禁止压力帧发送，也不绘制虚构的压力板。下方“导出动作分析…”可保存手部局部坐标和几何弯曲特征。这些特征用于数据分析，未经临床标定。
