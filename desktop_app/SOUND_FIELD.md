# 声场查看与接收板测绘

2026-10-14。入口为顶部“查看声场”或“声场”页，无须先打开调试模式。

## 1. 计算声场

“待发图形”使用编辑参数计算第一处焦点，不发送命令。“设备回读”使用最近收到的实际阵列、启用通道、相位及焦点；Demo 明确标为模拟回读。停用通道不参与叠加，输出关闭时图为零，回传过期时清除预测。移动焦点展示带快照编号的计算结果，不插补或宣称获得连续实测声场。

可选择 XY（与阵列平行）或 XZ（通过当前参考坐标的纵截面），查看相对载波声压、相对声压平方或相对 dB。“模型参数”展开阵列模板、口径与视野设置，默认收起以保留图表空间。右侧是穿过参考坐标的横向剖面。白线取切片峰值的半幅边界；尺寸为该峰值所在连通区域的采样估计，边界截断会提示。XZ 的全局峰值可能不在设置焦点，不应把它的宽度当成指定深度的横向分辨率。

## 2. 阵列与坐标

- 离线模板：4×4 样机为 11 mm 间距；8×8 R2 模板为 10.3 mm 间距（R1 历史板为 13 mm）。
- 连接后模板锁定，采用固件声明的阵列；模板不改变实际硬件或增加 MCU 通道。
- 任意三维坐标沿用“调试模式 → 设备设置 → 导入阵列坐标”，模型使用每路位置与朝向。
- 原点为发声面中心，z 正方向朝外。PCB 垂直桌面时，z 表示离板距离，并非离桌高度。从哪一面观察阵列、通道接线与坐标正方向必须一致。

本次只读核对 R5 的 PCB 网表与贴片坐标：按既有 MCU 接线，逻辑通道 0～15 对应 PCB OUT4～7、OUT0～3、OUT12～15、OUT8～11，位置与 11 mm 行优先坐标一致。实际装配、线缆和换能器安装高度仍须核对。

## 3. 模型与数值

模型叠加单频自由场传播 `p = Σ D(θ) exp(j(kr + sφ)) / r`，`φ` 来自相位码，`s=+1` 表示延迟码、`s=-1` 表示提前码。当前 F103/F411 的发生器使用 `(slot+code)%64<32`，码值增加使电气波形提前，真实回读自动采用 `s=-1`；Demo及离线默认使用抽象延迟码。其他真实控制器须在“模型参数”中核实并选择时序，否则不生成预测。相对单位固定为“单阵元轴上 100 mm 的单位载波幅值”；不会将每张图的峰值重新归一化为 1，因此通道减半或相消能显示出来。

等效圆活塞指向性采用 `D = 2 J1(ka sinθ) / (ka sinθ)`，考虑每路朝向与挡板背面的零输出；默认口径 10 mm 是模型假设，不是已标定的 MA40S4S 辐射口径。填 0 使用各向同性点声源。声速使用阵列几何声明。模型未包含器件固有幅相误差、反射、人体边界、驱动电压及换能器频响，不给出 Pa、dB SPL、真实总力或感知阈值。

## 4. 输出等级与校准

F103 通过开关完整载波周期控制等级，载波开启时仍为完整方波幅度。新页面与旧点声源参考页均不将等级线性乘到声压；预测显示载波开启时包络，不计算调制周期平均力。不同固件的等级实现须另行核对。

设备回读的相位已经包含板端修正，不重复添加 `phase_offsets`。没有测得实际声学误差时，模型不会把修正值的相反数当成已知器件误差。固定测点相位校准入口为“接收板测点 → 逐通道校准”；沿用已有四步干涉测量和来源/回读校验，仅在固件报告支持时可启动。当前声场页不生成 EDM 权重、不假装硬件具备每路独立幅度控制。

本轮还发现当前 MCU 求解器生成负距离相位码、发生器却将码值作为提前量使用，二者存在方向不一致的线索。声场页按实际发生器解释回读，不替板端美化成理想聚焦。离线理想相位不会发送给设备；本次仅修改上位机，没有修改或烧录固件。单测点校准可能补偿该位置的整体残差，但不能据此确认其他焦点也正确；应另行核验/修正板端求解方向。

## 5. 真实接收板测绘

接收板独立供 5 V，ADCV_P 接 MCU PA0，控制器与接收板共地。F103 使用 PA2/PA3 外接 USB-UART，默认 115200、8N1。

1. 固定发射阵列，将输出设为固定点、100%等级、关闭调制；明确启动输出。本页不会自动启动或改变发射配置。
2. 手动将接收器移动到已知位置，保持朝向和增益不变；填写 x/y/z，点击“采集当前测点”。软件不能检测接收器位置。
3. 每点请求三个 400 kS/s、200 点的 ADC 窗口，按坐标取 40 kHz 峰值电压的中位数，原始窗口全部保留。三次幅度波动明显会提示复测。
4. 移到下一个位置后重复。切换输出配置、阵列、设备启动标识或 Demo/真实来源时须新建测绘，避免混合数据。

测点颜色单位为 **ADC 端 40 kHz 峰值 mV**；仅显示当前 z 平面中实际记录的位置，未测区域留空，不插值补造声场。只有单接收器，必须移动才能获得二维分布。Demo 采样沿用合成波形，只验证工作流程，不模拟接收器在不同位置的真实幅值。

右侧同步画出当前单点的原始 ADC 波形，以及叠加直流偏置的 **40 kHz 拟合分量**。每收到一个有效窗口就更新；三次全部完成才保存测点。横轴是窗口内时间，默认展示前 100 μs，也可选择完整窗口（200 点、最后一点 497.5 μs）。统计显示整个窗口的直流、峰峰值、交流 RMS 和 40 kHz 峰值，单位均为 ADC 端 mV；拟合分量不是另一条实测波形，也不恢复前级削顶。

“波形窗口”可选择任意已保存窗口；点击左侧测点会选中该位置最近的窗口。位置、设备时间与来源随波形显示。历史波形按采集时保存的参考电压换算，随后修改参数不会重写历史数据。导入测绘 CSV 后也能回看原始波形；停止或断连后保留记录回放，取消未完成采集则回到上次已保存窗口，新建测绘会清除。

### 5.1 同坐标预测 / 实测对比

采集至少两个位置后进入“预测 / 实测对比”。对比从该测绘记录取阵列几何、启用通道、固定焦点配置和实际相位，在**每一个原始测点坐标**上计算预测；不使用当前草图或另一场测量的配置。新记录另存模型口径与相位码时序；修改当前预测页参数不会改写历史模型。旧 CSV 缺少模型时可手动选择口径/时序，真实记录不会依据当前连接设备猜测。

选择同一参考位置，分别计算 `模型幅值 / 参考位置模型幅值`、`40 kHz峰值电压 / 参考位置峰值电压`。两者在参考位置均为 1，而其他测点可直接比较。**不会将两边各自的最高点归一化**，也不会平移测点或改变相位让两边强行对齐。参考点信号为零或模型接近相消零点时拒绝归一化。

- 左图：底图为理论预测，圆点为实测，各用同一坐标、同一相对幅值色标，星号标记参考位置。
- 右图：x 剖面固定 y，y 剖面固定 x，显示该直线上的预测曲线与实际记录的测点。误差棒仅表示各次窗口的最小/最大读数，不是置信区间，未测位置不补线。
- 差异 RMSE 排除参考位置，因为该处一致是归一化强制的结果。单个位置明确提示不能验证空间分布；峰值位置只在已测位置内比较，不代表完整声场的最高点。
- “导出对比 CSV”逐位置保存原始电压统计、模型值、两侧归一化值、差值和参考/模型/输出上下文。原始窗口仍用测绘 CSV 保存。

对比以接收链路线性、增益及接收器朝向保持一致为前提，能检查相对空间分布，不能确定绝对声压、总能量或人体感知。Demo 采样只演示流程，不随手填位置生成真实声场响应，界面明确标注；不能用 Demo 的一致或差异验证声学算法。

## 6. 测量有效性

调制关闭和满等级用于避免 0.5 ms 窗口落在门控关闭段，从而把时间变化误当成空间变化。输出、启动标识或配置版本不匹配，或 ADC 触及量程边界时，不保存当前测点。STOP 可立即取消未完成测点；采集不完整时不追加部分窗口。

ADC 未触及电源轨不能排除接收板前级运放削顶；已经放大成方波的信号不能用于线性声压比较。必须先核验模拟链路。电压大也不等于声压大，换算 Pa 需要接收器灵敏度及整条链路的声学标定。

## 7. 导出与导入

“导出预测 CSV”逐格保存坐标、相对幅值及平方，第一行保存模型、阵列和相位上下文，来源固定标为 `THEORY_NOT_MEASUREMENT`。

“导出测绘 CSV”保存人工坐标、原始 ADC 点、采样时间、换算参数及输出/几何/相位上下文；来源为 `ADC_UNCALIBRATED` 或 `DEMO_SYNTHETIC`。新格式 `touchsee-field-scan-1` 可重新导入并根据原码重新核验分析值。最多 2000 个窗口、8 MB。导入记录是历史数据，来源按文件声明显示；旧 `x_mm,y_mm,value` CSV 仍从调试页导入。
