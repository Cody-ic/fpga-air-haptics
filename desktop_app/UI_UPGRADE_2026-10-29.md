# 触见工作台界面升级

日期：2026-10-29。范围为现有桌面程序的视觉、导航和显示适配，以及后续确认加入的 EgoPressure 真实顶点与压力板三维回放。不修改设备协议、图形文件格式或板端扫描程序。

## 页面与功能对应

| 入口 | 中央内容 | 右侧与配套操作 |
| --- | --- | --- |
| 三维回放（默认首页） | 真实手部顶点、关节连线与压力板；独立回放时间轴 | 压力热图、总力、峰值与缺失帧提示；详见 EGOPRESSURE_REPLAY.md |
| 掌心绘图 → 草图 | 原草图编辑器、绘图工具、撤销重做、适合窗口、放入掌面 | 对象属性：尺寸、关系、顺序；图形参数：位置、高度、重复频率 |
| 掌心绘图 → 预览 | 内置图案快捷选择及待发送图形预览 | 图形参数；不会因预览自动发送 |
| 播放查看 | 已接收图形、设备回传位置、暂停/跳转/断线反馈 | 图形参数与控制来源；草稿不冒充已应用配置 |
| 实验与设备 → 设备设置 | 模拟、串口、蓝牙连接；演示阵列配置 | 启用调试模式后显示阵列坐标导入导出和详细信息 |
| 实验与设备 → 调试模式 | 设备回读、电脑预测、实测数据、通信日志 | 实测数据内保留接收波形、扫描文件导入和相位校准 |

绘图与设备页顶部显示文件名、保存状态和连接状态，左侧保留图形导入与保存，底部固定发送和设备播放控制。三维回放页隐藏这些图形操作，使用独立数据导入与离线播放控制；顶部停止输出始终保留。独立 MG24 校准工具继续保持原有链路与入口。

## 实现说明

- 沿用 Tk，集中在 `theme.py` 管理颜色、字体和圆角按钮，继续保留键盘焦点提示、禁用状态及错误颜色。Pillow 成为运行依赖，用于抗锯齿按钮背景，不需要网络资源。
- 保留原页面对象和会话流程，由单一页面选择状态同步左侧导航；发送和开始播放后，自动跳转仍指向播放查看。
- 编辑器允许将对象检查器放在工作台右侧，草图几何和文件存储逻辑不变。
- 根据系统文字缩放设置初始及最小窗口尺寸，右侧和设备详细设置允许滚动；换行标签按可用宽度调整。
- 仅在显示文本或控件状态实际变化时更新，减少重复布局与绘制。编辑变量仍保留原有通知机制。
- 模拟、理论、设备数字回读、接收电压等来源标识保留。观察视图与设备输出保持分离。

## 验证入口

```powershell
python -m unittest discover -s desktop_app/tests -v
python -m desktop_app.tests.gui_smoke
python -m desktop_app.tests.receiver_gui_smoke
python -m desktop_app.tests.workspace_gui_smoke
powershell -File desktop_app/build_windows.ps1 -Python desktop_app/.runtime/build-venv/Scripts/python.exe
```

`workspace_gui_smoke` 覆盖 100%、125%、150%、200% 文字缩放下的最小窗口、三入口切换、草稿与坐标保留、无隐式命令、固定控制、检查器、连接、测量和校准入口，并输出界面截图。它通过 Tk 缩放模拟文字尺寸；不代表已经覆盖多显示器切换或所有 Windows 主题。

打包版的 `--self-test <输出目录>` 在现有绘图与模拟蓝牙检查后追加工作台缩放检查。结果和截图保存在指定目录，普通源码验证写入 `.runtime/`。`dist/` 内为可执行文件与便携压缩包。
