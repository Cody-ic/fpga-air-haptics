# 底面坐标与实时串口记录

## 测量时填写什么

“声场 → 接收板测点”默认采用 **P5 支架增加 30 mm 后的底面坐标**，单位 mm。

- 原点 O：左增高底座接触桌面的左前外角。
- 俯视时 X 向右、Y 向后；Z 从桌面向上。
- 接收板朝上，4 针接口朝右。此安装方向不能随意旋转。
- 默认填写接收头 R 的坐标；居中名义位置是 `(132,94,24.7)`。
- 也可选择“托盘左前角 A”。输入 A 的 X/Y，Z 仍填写接收头声面的离桌高度。
  软件计算 `R_X=A_X+33.273`、`R_Y=A_Y+20.128`。
- 点击“坐标示意图”核对原点、角点和接口方向。托盘有倒角，角点取直边延长线交点。

这些数值来自打印件装配尺寸，尚未实测校准。未装增高件、安装方向改变或高度改变时，不要直接套用；可继续选择“阵列坐标（旧方式）”。

## 软件如何换算

发射面中心位于底面坐标 `(132,94,124.7)`，阵列翻转后朝下。板端控制、相位计算、理论声场与对比运算仍使用原有阵列坐标：

```text
x_array = X_table - 132
y_array = 94 - Y_table
z_array = 124.7 - Z_table
```

所以居中接收头对应阵列坐标 `(0,0,100)`。Y、Z 都有方向翻转，不能只平移原点。软件不改变电气通道编号，也不会自动得知接收板的位置。

测点图和波形位置标签采用所选坐标；预测/实测对比图明确标注阵列坐标，其输入从测点坐标自动换算。计算声场页保持阵列坐标。切换坐标模式或定位点会保留同一物理位置。

每点采集三个窗口。开始采集时锁定位置与换算参数；中途取消则不保存未完成测点。测绘文件 `touchsee-field-scan-2` 同时保存 `x_mm/y_mm/z_mm`（阵列坐标）、`table_x_mm/table_y_mm/table_z_mm`（接收头底面坐标）、原始填写位置、定位点、变换参数和采样原码。旧版文件仍可导入，缺少底面定位信息时按阵列坐标显示，不猜测原始安装方式。

## 上位机占用串口时怎样读取

串口仍由上位机单独打开。连接后自动把数据镜像到：

```text
%LOCALAPPDATA%\TouchSee\live\latest.json
%LOCALAPPDATA%\TouchSee\live\<每次连接的独立目录>\
    session.json    连接方式、端口、波特率及是否模拟
    snapshot.json   最新设备状态、最新采样、更新时间和连接是否已关闭
    traffic.jsonl   原始收发字节及解析后的事件，每条写完立即刷新
```

调试模式的“通信日志 → 打开实时记录”可打开当前目录。助手直接读文件，无须再次打开串口：

```powershell
python -m desktop_app.live_log --summary
python -m desktop_app.live_log --follow --tail 10
```

原始记录包含 TX/RX 方向、十六进制字节和文字；损坏报文、拆分报文也保留。Demo、真实连接与断连状态明确区分。读取时须检查更新时间、端口和 `simulated`，断连后的历史状态不能当作实时状态。软件队列或写盘失败会显示提示，通信线程不会等待日志写盘。

这解决的是共享读取；助手不能通过日志向硬件发令。采样仍需真实采样器支持，坐标由人工填写，接收电压仍未标定为声压。
