# FPGA 空中触觉图形显示器

2026 年全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道参赛项目。

团队于 2026-09-14 拟选“面向视障人群的空中触觉图形显示器”方向，计划使用 256 路超声相控阵，在手掌附近生成可感知的触觉刺激和简单图形轨迹。当前处于方案论证阶段，尚无 HDL 源码、硬件工程或实测结果。

## 首版目标

- FPGA 内完成单焦点相位求解和多通道同步输出。
- 验证固定焦点触感，再实现直线、圆等简单轨迹。
- 测量更新率、声场分布及图形辨识效果，逐步验证 8×8 到 16×16 阵列。
- 多焦点、手部跟踪与声悬浮作为后续扩展，具体范围根据验证结果确定。

以上均为计划目标，不能视为已实现性能或已验证的无障碍产品能力。
