# P5 补充件：固定增高底座与薄膜观察架

2026-10-22，版本 P5-ADDON-20261022。适配已经打印的 [P5 支架](../overhead_setup/README.md)，同时兼容 4×4 和 8×8 发射板。只新增底座、压桥和膜框；原侧架、发射板承载框、5 mm 绝缘套筒及接收板托盘均保留，不重新打印、不打孔。

## 1. 布局与距离

- 两个固定底座把原发射支架整体抬高 **30 mm**，原 70 mm 名义声面间距变为 **100 mm**。
- 原接收板、接收器和托盘继续用于电路与声场调试，仍直接放在桌面上。接收板不垫高，不拆掉接收器，也不从原托盘借用紧固件。
- 薄膜观察架独立放置，使用时移出接收板托盘，换入膜架。两种测量目标互换使用，不能上下叠放在同一束声路上。
- 接收器声面距桌面名义高度 24.7 mm；膜片下表面也为 24.7 mm，10 μm 膜片上表面为 24.71 mm，因此发射面至膜上表面为 **99.99 mm，按 100 mm 使用**。
- 接收板原四针连接口、侧面窗口、12 mm 板下空腔和背面测试针避让均保留。发射板上方原 50 mm 连线预留随主体一起抬高。
- 横向位置仍由手动摆放确定；膜窗中心或接收器中心应分别对准阵列中心。底座未实现精密坐标定位。
- 控制软件中的焦距应对应距发射面约 100 mm；桌面以上 24.7 mm 是装配高度，不是软件焦距。保持原 70 mm 焦距不会自动对准增高后的测量目标。

上述距离基于原模型的焊高与板厚假定，装好后须量实际声面。100 mm 是本次机械目标，不代表已经验证聚焦、触觉或膜片可见形变。

## 3. 新增标准紧固件

这些零件需要另备，不能打印。螺丝长度不含内六角圆柱头。

| 安装位置 | 螺丝 | 普通六角螺母 | 平垫圈 |
|---|---|---|---|
| 两个增高底座 | M4×25，4 颗 | M4，4 颗，对边 7 mm、高 3.2 mm | M4，4 片，放压桥上方 |
| 膜框上下夹圈 | M3×16，8 颗 | M3，8 颗，对边 5.5 mm、高 2.4 mm | M3，16 片，上下各一片 |

## 4. 增高底座装配

1. 先打印 `12_riser_fit_coupon.stl`。用已打印侧架的底梁试入 16.6 mm 槽，并试装普通 M4 螺母。原底梁名义厚 16 mm，每侧间隙 0.3 mm；真实打印尺寸未知，不能靠硬砸配合。
2. 两个正式底座平放桌面。底座中间的长槽朝上，原侧架底梁分别完整落到槽底。底座承托面距桌面 30 mm。
3. 每个底座从两侧开口各放入一颗普通 M4 螺母，平行边贴合 7.3 mm 宽的防转槽。
4. 每个旧侧架下方窗口内放一块压桥，跨过中间的旧底梁。两颗 M4×25 螺丝加垫圈，从压桥两端向下穿入并拧入螺母。
5. 交替轻拧，使压桥贴住底梁、旧件不窜动。压桥用于压紧，不用于把塑料拉弯。确认两侧均固定、底座不翘起后再装发射板；首次空载检查后再逐步承载。

底座不依赖胶粘或新的打印螺纹。其抗滑、打印层结合和载荷能力尚未做实体测试。

## 5. 4×5 英寸、10 μm 薄膜装配

膜片外形为 **101.6×127 mm**，没有自带边框，材料尚未确认。上下框外形 122×148 mm，中央悬空窗口 **91.6×117 mm**，膜片四边各留 5 mm 夹持宽度。

1. 下架打印时大平圈贴打印平台、四脚朝上；使用时翻转，使四脚落桌。上圈平放打印。两圈接触膜片的一面均应修平、清除颗粒并轻轻修圆内口棱边。
2. 将下架四脚朝下放在干净平面上。膜片居中铺在下圈上，长边与长边对齐，移除确认属于包装的分离保护层，不将叠放的多张膜当作单张。
3. 覆上上圈，装入 8 颗 M3×16 螺丝。所有孔均在膜片外缘之外，**不在膜上打孔**。上下金属垫圈仅接触打印框，不能压到悬空膜区。
4. 对称、分次轻拧螺母，同时用手调整四边，使膜面尽量平整。只消除明显褶皱，不以猛烈拉伸获得张力。本设计是手动夹持，不是恒张力装置。
5. 检查膜下方窗口完全悬空，接收板不在其下方。将窗口中心对准发射阵列中心，再开始短时测量。结束后松开夹框即可更换膜片。

不设置 10 μm 打印槽，也不要求打印机制造微米级配合。膜厚用于装配参考；未知材质、张力和打印表面会影响实际效果，预览图不表示已算出膜片形变。

## 6. 返回接收板调试

将整个膜架移走，再把原接收板托盘放回阵列下方。接收器朝上、四针口保持原接线，电路和原托盘不用拆。连接线从侧面引出，禁止夹在新增底座或旧底梁下面。底座中间留出原接收板的移动区域；测试针仍从原板下空腔或侧面接触，探针接法按接收板原电路说明执行。

新增底座比旧底梁宽，因此不沿用原 P5 的全部移动范围。接收板整组模型在中心位置沿左右、前后各平移 ±20 mm 时，距增高底座仍有至少 5.27 mm 横向间隙；这是板件和紧固件包络检查，不含实物四针插头与外接线的弯折。调试时连接线留松弛并向前、后方引出，不能拉紧线缆追求模型极限位置。

对比薄膜与接收板时保持同一张桌面、同一阵列中心和同一软件焦点高度。横向摆放误差、真实焊高和膜面起伏需另行记录，不能把两次信号差全部归于声场。

## 7. 源文件、检查与复现

- `parameters.json`：增高量、膜尺寸、窗口、槽宽和紧固件参数。
- `build_addons.py`：生成原生零件和四套装配体，草图使用尺寸及几何关系完全定义，不使用“固定”关系替代约束。
- `check_addons.py`：检查新网格、声面高度、夹持宽度、螺丝避膜、原接收装配保持不变；`--native` 重新打开原生文件并检查装配干涉。
- `render_addons.py`：从最终导出网格生成预览，电子件和连线仍为原模型的名义包络。
- `package_addons.py`：只在两份核验报告通过后发布，逐文件校验旧件原样复用与打印数量。

从仓库根目录运行（需已安装并授权的 SOLIDWORKS 与 Python 的 pywin32、numpy、trimesh）：

```powershell
python hardware/mechanical/overhead_addons/build_addons.py
python hardware/mechanical/overhead_addons/build_addons.py --assemble
python hardware/mechanical/overhead_addons/check_addons.py
python hardware/mechanical/overhead_addons/check_addons.py --native
blender --background -t 4 --python hardware/mechanical/overhead_addons/render_addons.py
python hardware/mechanical/overhead_addons/package_addons.py
```

复现依赖原 P5 已核验模型，生成脚本会先核对原文件散列，不能拿外形相近的其他侧架代替。新件的真实试配、承载与声学测试仍待完成。
