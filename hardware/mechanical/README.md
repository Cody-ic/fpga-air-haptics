# 4×4 阵列夹具与可调腕托

## 1. 版本与用途

P3，2026-09-30。配套现有 R5 四层 PCB、4×4 MA40S4S 阵列，中心间距 11 mm。

本版去掉焊装夹具上的四个 PCB 支撑凸起，改为 **87×95×5 mm 平整通孔板**，保留电阻避让窗。16 个换能器的前端外缘仍共同贴靠独立平整基准板。**PCB 改用独立夹具托住并固定，不能让它靠引脚悬挂。** 腕托结构、阵列坐标及 PCB 均未改动，P1/P2 归档继续保留。

- **阵列定位夹具**：焊装时统一换能器发声端面的高度，完成后取下。
- **可调腕托**：支撑手腕，让手掌悬空，阵列正上方不放支撑板。腕托中心相对发声面可调约 44–104 mm，默认约 70 mm，均不含软垫。

这是一套待试打的机械原型，尚无实物配合、承重或人体舒适度测试。这里的高度是机械尺寸，不代表已经验证的声学工作距离。本版只做平面 4×4，不包含球冠。

## 2. 文件怎么用

从仓库下载 [P3 完整设计与打印包](P3_20260930/TouchSee_4x4_Print_P3_20260930.zip)，解压后保留文件夹结构。只需要新夹具时，将 [P3 学校打印包](P3_20260930/TouchSee_Jig_STL_P3_20260930.zip) 交给打印人员，里面只有夹具和孔径试片两个 STL；各打印 1 件，试片先打。包内没有基准板、PCB 或换能器模型，避免误打印参考件。日常生成的 `dist/`、`.runtime/` 和临时截图继续忽略。

本机重新生成时，交付目录为 `dist/P3-20260930/`，压缩包位于 `dist/TouchSee_4x4_Print_P3_20260930.zip`。解压包内的仓库下载链接可忽略，直接使用同目录文件。旧版见 [P1 归档](P1_20260929/TouchSee_4x4_Print_P1_20260929.zip)和[带支撑柱的 P2 归档](P2_20260930/TouchSee_4x4_Print_P2_20260930.zip)。

| 文件夹 | 用途 |
| --- | --- |
| `solidworks/` | SolidWorks 2025 原生零件和两个装配体；请保留整个文件夹，避免丢失零件引用 |

先打开 `Wrist_support_assembly.SLDASM` 看腕托，或 `Array_jig_assembly.SLDASM` 看焊装夹具。装配体采用固定位置展示，尚未建立可拖动的滑槽配合；调整高度需编辑位置或重新生成。

**10 个原生零件共 15 张草图均已完全定义**，采用尺寸和几何关系，没有使用“固定”草图关系。STEP/STL 仅用于交换与制造，不能保留这些草图。草图可以在原生零件中编辑；修改后要重建并重新导出打印文件。

暂按 200×200×200 mm FDM 打印机设计。最大件底座为 150×188×156 mm，注意切片软件的实际可用区域及裙边。

| --- | --- | ---: | --- | --- |
| `01_array_alignment_jig` | 阵列焊装夹具 | 1 | 87×95×5 | 平放，无支撑凸起 |
| `02_bore_fit_coupon` | 孔径试片 | 1 | 62×20×5 | 平放 |

| `05_pcb_standoff_35` | PCB 垫柱 | 4 | Ø8×35 | 竖直打印，可加裙边 |
| `06_m4_nut_knob` | M4 手拧旋钮 | 2 | Ø22×9 | 六角螺母槽朝上 |

先打印试片，将本次使用的 16 只换能器逐只试配。试片缺角所在端为第一孔，依次为 **Ø10.0、10.2、10.4、10.6 mm**。选择所有器件都能轻松滑入、无需压挤外壳的最小孔径；正式夹具默认 Ø10.4。不要整体缩放模型来调孔，否则 11 mm 间距和 PCB 安装孔也会改变。

PLA/PETG 均可先用于试打。可从 0.4 mm 喷嘴、0.2 mm 层高、主体 4 层外壁、35–40% 填充开始；这不是经实测确认的强度参数。夹具相邻孔间最薄处只有 0.6 mm，切片时检查薄壁是否被保留。所有零件按给定方向设计，通常不需要大面积支撑；仍应查看逐层预览，尤其是立柱槽顶的小桥接。热床上的底座裙边建议不超过 5 mm。

## 5. 如何保证阵列端面共面

**真正的高度基准是下面的平整基准板，不是打印件的孔底。** 打印夹具负责横向定位，独立工装负责支撑 PCB；单靠打印精度不能保证严格共面。

1. 将夹具大平面放在基准板上。清除毛刺、首层凸边和孔内拉丝，确认夹具不晃动。
2. 逐个试插，确认孔内全程可自由滑动，不能卡在半空。16 个换能器发声面朝下插入孔中，让前端外缘轻靠同一基准面。不得向网罩、喇叭口或外壳施加夹紧压力；若前端结构无法让外缘稳定接触，应停止并按实物重新设计接触面。
3. 用独立焊接夹具托住 PCB，使换能器安装面朝下、焊接面朝上，再套入引脚。调整 PCB 高度和相对基准板的平行度，给壳体背面留出间隙。核对引脚及极性，不能假定每个位置朝向相同。
4. 检查 PCB 已独立固定、所有前端外缘仍贴住基准板；不要用 PCB 压紧换能器，也不要让引脚或孔壁摩擦把换能器带起。每只先点焊一脚，一轮后复查贴合，再焊另一脚。遵守器件手册的焊接温度与时间要求，避免烙铁碰到打印件。
5. 冷却后整体提起，沿换能器轴向轻轻退出夹具。确认没有夹死、扯动焊点，再检查端面高低差与焊点。

装配模型保留基准面到 PCB 安装面 **10.6 mm 的名义位置**，这需要外部夹具设置，不再由打印件限高。按壳高 7.1±0.3 mm，对应壳体背面到 PCB 约 3.2–3.8 mm；不要强行压到贴板。夹具孔内不得放螺钉头撑起底面。实际安装距离改变时，应复测相对 PCB 的发声面高度；腕托净空按实物重新确认。

避让窗位于阵列局部坐标 X=25.5…33.5、Y=−36…−11 mm，覆盖 R5 正面的 8 个电阻；其位置来自贴片坐标文件。装配参考用每个 3.0×1.6×1.2 mm 的假定包络检查空间，**不是厂商精确模型或实测尺寸**。其余背面电子元件没有完整建模。

焊后应检查 16 个前端外缘的相对高低差，记录最高与最低的差值及测量方式；不能以 STL 的理论 0 高度差作为验收数据。比较同一外壳基准位置，不测网罩中心，也不要用探头压网罩。前端外缘共面不等于内部声学相位天然一致，后续仍可按接收反馈校准。

这个夹具用于焊装，不作为永久声学面板。**试验发声前移除夹具**。已经焊好的阵列若高度不一，单把夹具套上不能矫正焊死的器件。

## 6. 腕托装配与调整

先将四个垫柱装在底座上，再用现有四个安装孔固定 PCB，换能器朝上。孔位已与 R5 Gerber 的四个非金属化孔逐一核对，不需要改 PCB。

PCB 底面至底座上表面名义间距为 35 mm。C1 对应的 Panasonic EEUFR1V102 壳体高度为 20 mm；本版装配模型没有完整画出背面元件、插头和线缆，装配前仍需确认实际元件、焊脚及插拔空间。

把腕托平背面贴住两侧立柱前侧，两个 M4 螺钉从腕托侧穿过长槽，立柱后侧放垫圈与旋钮。两柱中间留出 94 mm 开口供前臂伸入，没有整片背板挡住前臂。旋钮六角孔装 M4 螺母。松开两侧、保持腕托水平、调高后重新拧紧，调节时不要压住腕托。

贴软垫并包覆接触边缘，手腕轻放在弧面上，手指朝阵列另一端伸出，手掌悬在阵列上方。约 3 mm 软垫会抬高接触面，但手掌实际高度还受姿势与压缩量影响。腕托用于减轻悬空负担，不承担起身时撑压的身体重量；在无人使用时先验证锁紧与稳定性。

- 重新打开并重建 10 个原生零件，15 张草图全部完全定义，固定关系数为 0。
- 两个原生装配体均可重新打开，零件数量、变换位置正确，已建模实体之间无体积干涉；腕托最低和最高位置也通过干涉检查。接触面不视为干涉。
- STL 均闭合、方向一致，六种打印件各为一个连通实体，尺寸满足假定的打印空间。
- STL 与 CAD 体积偏差低于 0.1%。夹具最高点为 5 mm，原四根支撑柱位置均已核验为平面。
- 校验 16 个名义前端与同一 Z=0 基准面贴合；对导出网格进行 784 次垂直探测，确认采样位置没有底面或挡肩托起换能器。按 R5 的实际 XY 坐标复核 8 个正面电阻的避让窗。
- 没有实物试打、承重、人体适配和声学测试；未包含独立 PCB 夹具、紧固件、软垫、全部电子元件的完整干涉检查。

核验记录见交付包中的 `native_validation.json`、`validation.json`、`travel_validation.json`。

## 8. 修改与重新生成

源文件为 `build_solidworks.py`、`assemble_solidworks.py`、`pcb_layout.py` 和 `parameters.json`。在安装 SolidWorks 2025、Python、pywin32 和 NumPy 的本机运行：

```powershell
python hardware/mechanical/build_solidworks.py
python hardware/mechanical/assemble_solidworks.py
python hardware/mechanical/check_solidworks.py
python hardware/mechanical/validate_models.py
# 使用本机 Blender 生成真实模型预览后再打包：
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python hardware/mechanical/render_preview.py
python hardware/mechanical/package_release.py
```

脚本中的 SolidWorks 安装位置和模板目录按当前电脑设置，换电脑需调整。`guide_bore_mm` 可改试片选定的孔径，`wrist_bolt_height_mm` 可在 82–142 mm 范围内改默认装配高度。其他结构尺寸不是全部由 JSON 联动；本版明确限定 4×4、11 mm 间距，扩阵列要重新设计，不能只改行列数。

重新生成会覆盖同版本输出，手工修改的原生文件应先另存。生成器会在每张草图建立尺寸及几何关系，并在无法完全定义时停止，不会默默导出欠定义草图。
