# 接收端与薄膜的 20 mm 增高垫

2026-10-25。两件独立垫子均用于**垫高原有支架**，不替代接收托盘或薄膜夹框。原件保持不变。

## 打印与装配

| 文件 | 用途 | 数量 | 外包尺寸/mm |
|---|---|---:|---|
| `13_receiver_tray_lift20.stl` | 放在原接收托盘下 | 1 | 82.8×61.419×22 |
| `14_film_stand_lift20.stl` | 放在原薄膜支架四脚下 | 1 | 128.8×154.8×22 |

每件为一体结构，承托面 Z=20 mm，定位挡边高2 mm，总高22 mm。单侧预留0.4 mm装配间隙，定位壁厚3 mm。挡边只接触原托盘或支脚底部，低于接收板、背面测试针及接口；板下空腔与现有接线方式不变。薄膜垫中央开口95.6×121 mm，大于原91.6×117 mm观察窗。

- 接收端：桌面 → 13号垫子 → 原05号托盘 → 接收板。
- 薄膜端：桌面 → 14号垫子 → 原10号薄膜支架四脚 → 原上下夹框与膜片。
- 两种目标互换使用，不能同时叠在声路上，也不要叠放两个增高垫。
- 不新增螺丝或滑动机构，不改原件。取下旧组件即可恢复原高度。
- 平底朝下打印；每个文件只需打印1个，无额外小件。材料及切片建议见[打印说明](打印说明.txt)。

打印后先空装检查。0.4 mm单侧间隙为设计值，尚无实物适配结果。

## 坐标和高度

原接收面与膜面名义离桌高度24.7 mm，垫高后均为44.7 mm；薄膜上表面44.71 mm。采用既有30 mm发射端增高件时，发射面高度仍为124.7 mm，接收面间距为80 mm，薄膜上表面间距79.99 mm。若发射端未加装30 mm增高件，则间距为50 mm。

软件选择底面坐标时输入接收面 Z=44.7；使用原阵列坐标时，对应居中测点 `(0,0,80)`。不能继续沿用旧的Z=24.7或100 mm焦距。

原托盘在新垫子内居中时，托盘左前角相对新垫子的左前外角偏移 `(3.4,3.4)` mm。因此量取新接收垫左前角 B 后，保持既定朝向时：

```text
接收头 X = B_X + 36.673
接收头 Y = B_Y + 23.528
```

软件的“托盘左前角 A”仍指原05号托盘；不要把新垫子外角误填为A。0.4 mm装配间隙允许原托盘微动，需量实际边缘，不能将设计居中位置当作实测值。以上小数用于模型定位，不要求手工测到微米。

薄膜增高垫以声轴为中心放置时，距右侧发射端增高底座名义净距3.6 mm，应居中使用。接收端仍可手动移动；实际接头与线缆弯曲空间须装配时确认。

## 文件与核验

生成脚本复用现有原生建模接口，两件共4张草图均以尺寸及几何关系完全定义，无固定关系。重新打开模型检查特征，两个“新垫＋原支架”装配均检查干涉；独立网格检查承托面高度、单一闭合实体和膜窗镂空。检查不等同于实物试装或声学验证。

成品位于[打印与模型目录](../P5_lifts20_20261025/)；其中打印压缩包仅含两份网格和简短说明，原生零件与中间交换文件单独提供。`build_lifts.py`生成模型并进行原生检查，`render_lifts.py`复用Blender渲染原始网格，`finish_lifts.py`检查网格、组合预览并打包。所有尺寸来自`parameters.json`及既有P5模型参数。
