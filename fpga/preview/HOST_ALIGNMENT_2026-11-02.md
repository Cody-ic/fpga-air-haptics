## 对照结论

屏幕原实现能够显示点、预设轮廓和自定义多段轨迹的理论声场，但未支持后来加入的静态压力相位表。旧代码会主动屏蔽静态模式的热图；合并发射版还沿用“仅预览 · 实际发射关闭”固定字样。此次修正这两处差异，并补齐设备状态和参数；不把电脑的完整编辑器搬到屏幕。

| 功能 | 电脑端 | 本次屏幕端 |
|---|---|---|
| 预设图形、自定义多段路径 | 编辑、发送、播放 | 保留当前轨迹的理论场显示 |
| 压力单帧 | 从数据集取帧、求解64路名义相位、发送 | 按完整名义相位表计算理论场；不再假定单焦点 |
| 发射与播放状态 | 状态回读 | 独立显示发射使能、播放/暂停/停止、图像有效 |
| 配置 | 编辑、发送、回读 | 只读显示截面高度、等级、轨迹频率、调制和载波频率 |
| 控制来源 | 电脑/本地切换 | 显示本地状态；非本地为电脑控制 |
| 三维数据回放、导入、草图约束编辑 | 已实现 | 保留在电脑，不在当前视频逻辑中复制 |
| 触摸操作、接收器实时声场 | 尚需独立链路与驱动 | 未实现，不绘制虚假可点击控件 |

## 实现与语义

- `hap2_top`和`board_top`只增加只读观察信号，发射、停止、心跳和串口协议不由显示逻辑接管。跨时钟快照从189位扩为768位，包含64路名义相位、静态模式、实际发射使能、本地模式和频率参数；整个快照经同一次请求/应答锁存。
- 静态表直接转为场引擎使用的相位码。硬件发射仍叠加实测补偿一次；理想显示不叠加补偿，不把修正换能器误差的偏置当成额外声场整形。
- 单焦点保留焦点十字标记；静态相位模式隐藏标记，轨迹频率显示横线。静态配置中的POINT字段不代表真实峰值位于中心。
- 等级以设备配置值显示，颜色仍代表单位激励的归一化理论幅值，不随等级假装线性缩放。此图没有Pa或触觉强度标定，也不表示数据集的接触压力被准确复现。
- 暂停时允许保留理论帧，同时关闭发射使能；停止和配置变更令旧帧失效。新的相位表不能与旧的场图混用。发射使能仅表示数字控制状态，不能证明发射板有电或实际声压存在。
- 数字显示支持轨迹频率0.010～200.000 Hz、调制0～1000 Hz，避免三位整数饱和。发射状态不再使用固定“关闭”字样；独立纯预览版仍在逻辑和物理引脚上强制关闭发射。
