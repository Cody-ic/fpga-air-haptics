# CAL2 上电校准串口

日期：2026-10-22。仅在 `FPGA_CALIBRATION_ENABLE=1` 且尚未 RELEASE 时占用现有板载串口；原有 HAP3 控制模块保持复位。RELEASE 应答完整发完后切换回 HAP3，不能继续发送校准包。波特率沿用板级设置，默认 115200、8 位数据、无校验、1 位停止位。

## 包格式

固定 34 字节，所有多字节整数为小端：

| 字节 | 含义 |
| --- | --- |
| 0–1 | `A5 5A` |
| 2 | 版本 `2` |
| 3 | 类型 |
| 4–7 | 本次 FPGA 启动标识 `boot` |
| 8–11 | 测量编号 `token`；普通管理命令使用 0 |
| 12–31 | 五个 32 位参数 `v0..v4` |
| 32–33 | 前 32 字节的 CRC16-CCITT-FALSE，小端；多项式 0x1021、初值 0xFFFF |

板端 50 ms 未收到完整包会丢弃半包。校验失败、版本错误或启动标识不匹配的包不执行。错误参数和当前状态不允许的命令不执行；电脑等待超时后报错，不自动重发控制命令。所有管理命令未使用参数必须为零。

## 电脑到 FPGA

| 类型 | 命令 | 参数 |
| --- | --- | --- |
| 1 | READY | `v0=来源(0示波器/1自动)`，`v1=是否复验已上传候选表`，其余 0 |
| 2 | MEASURE | `token=当前请求编号`；`v0=幅值平方`，`v1=质量有效0/1`，`v2=来源`，`v3=通道|(步骤<<8)`，`v4=本条件重复序号0..2` |
| 3 | PING | token、参数均为 0；电脑每 0.5 秒发送一次 |
| 4 | ABORT | token、参数均为 0；取消当前轮次，保留旧修正表 |
| 5 | READ_TABLE | token=0；`v0=16通道对齐的起始编号`，`v1=0保存修正/1理论相位`，其余 0 |
| 6 | RELEASE | token=成功轮次最后编号，参数全 0；仅 DONE 可执行 |
| 7 | SETUP | token=0；`v0/v1/v2=X/Y/Z微米`，`v3=等级1..100`，`v4=参考通道`；X/Y 采用 32 位有符号补码 |
| 8 | UPLOAD | token=0；`v0=16通道对齐起始编号`，`v1..v4` 的16个字节为候选修正，每字节0..63 |

SETUP 的 X/Y 范围 ±100000 µm，Z 为 20000..300000 µm；只在空闲或失败后允许，清除候选上传完成标记并重算理论相位。电脑收到配置确认、等待理论表就绪、读取理论表后才能 READY。READY 必须与编译来源一致，参考通道修正必须为零，导入模式必须已上传所有通道。失败后可以显式重新 SETUP 和 READY，不自动重试。

测量编号在同次复位内跨轮次单调递增，每个新请求增加一次。只有编号、通道、步骤、重复序号、来源均对应当前请求时才锁存测量值。错误包、旧包或重复提交均不推进。功率范围为 0..0xFFFFFF。

## FPGA 到电脑

| 类型 | 含义 | 参数 |
| --- | --- | --- |
| 0x80 | STATUS，每100 ms报告 | 见下表 |
| 0x81 | TABLE | `v0=起始编号|(表选择<<16)`，其余16字节为相位值，尾部不足16路补零 |
| 0x82 | RELEASED | 参数同 STATUS，发完后交还 HAP3 |
| 0x83 | SETUP_ACK | 五参数原样回显，确认锁存配置，不代表理论表已经计算完成 |
| 0x85 | UPLOAD_ACK | 五参数原样回显，只确认候选表上传，不代表应用成功 |

STATUS 的 `v0` 四个字节依次为状态、步骤、目标通道、错误。`v1` 位0 busy、位1保存表有效、位2来源、位3曾启动、位4配置及理论表已就绪、位5导入复验、位6输出使能，位8..9为重复序号。`v2` 四个字节依次为列数、行数、等级、参考通道；`v3=Z微米`，`v4=阵元间距微米`。

状态：0 IDLE、1 SETTLE、2 REQUEST、3 SOLVE、4 DONE、5 FAILED。步骤：0 背景、1 参考单路、2 目标单路、3..6 四个附加相位、7 修正后双路复测。背景和参考单路步骤中的目标通道字段仍保留下一目标编号，实际输出依据步骤判断。

错误：1 取消或心跳超时、2 测量超时、3 无效质量/范围/重复不稳定、4 单路过弱、5 四步拟合异常、6 修正后复验失败、7 编号空间或配置保护。0 表示无错误。

自动采样每次等待上限6秒，示波器每次120秒。忙状态3秒无有效心跳/测量则取消；停止发射后不继续推进。校准全部成功才统一提交新表；候选导入也必须重新测背景、参考、每路单路及修正后的双路幅值，不直接写入保存表。

## 指标与理论边界

自动来源的功率为 `round(peak40_adc²)`；人工来源为 `round((Vpp_mV/2*4095/3300)²)`，测量节点固定 ADCV_P。原始数值和来源保存在电脑记录，3300 mV 为名义参考值。

人工背景只作弱信号门槛，不参与频点功率扣除；自动背景从频点功率中扣除。单路功率须高于背景25倍，重复功率极差通常不得超过中位数15%（小于等于4个功率单位的极差允许）。四步拟合检查和修正后验证仍由 FPGA 完成，判断阈值是工程起点，尚待实测核对。

理论表与保存修正表使用不同 READ_TABLE 选择，电脑文件也明确区分 `theoretical_phases` 和 `phase_offsets`。协议不把理论相位标记为实测修正，不支持自动选择来源或无线传输模式。
