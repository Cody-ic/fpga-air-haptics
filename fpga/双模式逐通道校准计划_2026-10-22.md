# 以理论相位为基准，实现双模式实测校准

日期：2026-10-22。这是本轮用户确认方案的归档，作为后续开发与验收依据。进度见 [交接文档](逐通道校准交接_2026-10-22.md)，具体操作见 [校准说明](CALIBRATION.md)。

## 1. 宏定义与连接

在 `feat/mg24-receiver` 分支继续开发：

```verilog
`define FPGA_CALIBRATION_ENABLE 0
// 0：保持原有业务；1：开启校准入口
`define FPGA_CALIBRATION_SOURCE 0
// 0：示波器人工读数；1：ADC 自动采样，经电脑转发
```

FPGA（Field Programmable Gate Array，现场可编程门阵列）两个宏的非法值均构建报错，默认关闭校准，默认来源为示波器。ADC（Analog-to-Digital Converter，模数转换器）由 MG24 采集。

- 示波器模式：接收板 → 示波器 → 人工输入电脑 → FPGA。
- 自动模式：接收板 → MG24 → USB／蓝牙 → 电脑 → FPGA。
- MG24 保留自己的 `MG24_USE_BLUETOOTH` 通信宏：0 使用自带 USB，1 使用蓝牙；FPGA 不增加有线／无线宏。
- 上电关闭输出，电脑核对来源、用户确认摆放后开始。示波器模式不需要 MG24；自动模式先验证接收端能采样。
- 开发、构建不自动烧录。2026-10-22 用户另行授权识别成功后下载，已完成示波器版临时下载；后续烧录仍按明确授权和目标设备核对执行。

## 2. 理论基准与校准流程

- 根据实际阵列参数和填写的接收位置计算理论聚焦相位，各路实测修正初值为零。
- 此前 MCU（Microcontroller Unit，微控制器）的理论表仅用于同一测点、频率、档数和通道映射下的计算对照，明确标记为理论数据，不导入为实测修正。
- FPGA 依次控制背景、参考单路、目标单路、两路四相位测试及修正后复测，每个条件测三次。
- 相位求解与应用均在 FPGA 完成。全部验证通过后统一提交修正，失败保留旧表。
- 最终输出为理论相位加实测修正，按 64 档取模。本轮修正只应用于 40 千赫、64 档；其他设置关闭输出并提示不兼容。
- 完成后保持停止，再交还原有控制流程。

## 3. 独立中文校准窗口

- 提供串口选择、接收坐标、测试等级、参考通道、开始、停止、重新开始及保存结果。
- 默认接收位置 `(0,0,100) mm`、等级 `30`、参考通道 `0`；开始前要求确认实际摆放和通道接线。
- 显示当前通道、附加相位、测量次数和输出状态。
- 示波器模式逐次输入 `ADCV_P` 处的毫伏峰峰值，并确认未削顶；提交后才推进，每次等待上限 120 秒，超时关闭输出并允许重新开始。
- 自动模式复用 MG24 采样协议与客户端，校验启动标识、请求编号、质量和新窗口，拒绝旧结果。
- 两种来源统一换算测量尺度。人工模式只接受稳定、近正弦、无削顶波形；背景峰峰值用于弱信号检查，不直接当作频点噪声功率扣除。
- 扩展现有校准协议传递来源、位置、通道、步骤和编号；错来源、错编号、重复提交均不能推进。断线或取消关闭输出。

## 4. 保存、验证与交付

- 保存理论基准、原始读数、测量来源、测试条件、实测修正和验证结果，明确区分理论与实测。
- 支持实测修正文件导出及导入后逐路验证；理论表不能通过实测修正导入入口。
- 修正保存在板内存和电脑文件，断电后重新导入，无需逐通道烧录。
- 构建正常业务、示波器校准和自动采样校准配置；仿真覆盖全部 64 档相位、16 路顺序、修正应用、异常读数、超时、取消和断线，并回归原有 FPGA 测试。
- MG24 固件不变时复用已有验证；若修改其公共代码，再编译检查 USB 和蓝牙两个分支。实板只烧录选定的一版。
- 交付中文窗口、构建脚本、日志、产物，以及临时固定、接线、示波器设置和削顶排查说明。构建产物、下载包与缓存保留本机，源码和验证摘要提交仓库。
- 实测效果由后续硬件测试确认，编译通过、数字串口回读和合成信号测试均不能替代声学验证。

## 5. 后续验收顺序

1. 确认板卡下载和校准状态可读，空闲输出关闭。
2. 固定接收端，示波器核对背景、单路与双路波形，先解决削顶或弱信号。
3. 完成一轮人工校准并保存真实记录，检查修正后复测与失败停机。
4. 导入真实修正文件，逐路验证通过后再交还原控制程序。
5. MG24 接入后先独立验证采样率、量程和 USB／蓝牙通信，再完成自动来源的完整校准。
6. 最后做固定接收点的焦点扫描与模型对照；全空间声场和触觉图案效果另行验收。
