# F103 优化与实板联调记录

## 验证条件

- 日期：2026-10-07；STM32F103C8T6 实板，64 MHz，ST-LINK V2。
- 串口：CH343，COM4，115200、8N1、无流控；PA2 TX、PA3 RX。
- 引脚：逻辑通道 2 使用 PA8，其他通道保持原 PB 映射；`.ioc` 与生成代码一致。
- 压力测试输出等级为 0，保留实际定时器、双 DMA、几何计算和 ADC 采集工作；不驱动换能器。
- PA0 输入来源及接收板供电未确认。ADC 结果只用于验证采集、传输、解析与记录，不用于判断声压、灵敏度或触觉。

## 修复内容

原回填计算超过 250 μs 缓冲周期；串口接收又被波形中断延迟，输出故障处理还会丢掉正常的首个 HELLO。采样回复期间每次只准备一路相位，也会耗尽焦点队列。

当前将整数相位求解与线段长度缓存用于 F103，提前计算四个焦点；后台服务每次完成一个焦点，DMA 中断仅复制已准备的位图。缓冲使用固定大小的字拷贝与填充。USART2 优先于波形 DMA，ADC DMA 优先级最低。输出故障保留正常接收队列，UART 错误单独重新同步。共享协议临时空间节约 RAM。

40 kHz 载波、64 相位槽、1 kHz 焦点、250 μs 缓冲、25 μs 关闭检查窗口及原驱动/接收接线均保留。上述频率是定时配置，尚无示波器确认。

自动启动检查使用默认输出等级 30%，只核对数字执行状态，未确认驱动板供电或实际波形。测试结束发送 STOP，MCU 保持 LOCAL/IDLE；重新上电仍会等待 3 秒自动启动。

计时覆盖本次测试，不能作为所有参数组合的最坏执行时间保证。整数相位与桌面双精度参考在 1,027 个焦点坐标上相差不超过一个相位码；距离截断可能跨越量化边界。几何缓存检查容差为 3 μm，这些均为数值检查，不能推断物理精度。

## 复核方式与下一步

```powershell
python firmware/stm32f103c8_cube/build.py
python firmware/stm32f103c8_cube/tests/test_f103.py
python firmware/nucleo_f411re/tests/test_firmware.py
```

实板可用上位机真实串口连接，配置图形后播放，在调试模式请求“接收波形”。先测输出频率、跨端口同步、相位和停止行为，再确认接收输入范围与校准，最后验证声场及触觉。无需为本次优化改动 PCB。
