# 静态多点与圆环参考算法

## 1. 用途与状态

2026-10-30。独立电脑数值参考，研究64路同时发射、只调相位时能否形成静态多点及半径20 mm圆环。
这不是单焦点扫描的时间平均，也不是屏幕上绘制一个目标轮廓。每幅预测图对应一套固定的64路相位。
不包含串口、硬件下载、实际发射或板端求解实现；没有改变原业务程序。

## 2. 几何与假设

- 8×8平面阵列，间距10.3 mm，通道顺序复用 `desktop_app.model.array_coordinates`。
- 40 kHz、声速343 m/s，工作平面50 mm；圆半径20 mm。
- 各通道单位幅度，求解64个连续相位，再量化为64档；没有用自由幅度控制换取图形。
- 理想同型号、同幅度且无残余相位误差。未将实测校准修正当成传播特性直接相加。
- 两种模型：与现有上位机一致的各向同性点源，以及假设直径10 mm均匀圆活塞指向性。
- 活塞模型不是MA40S4S实测曲线，外壳直径不等于有效声学直径。两种模型分别求解，只能用于比较模型敏感性，不能证明真实器件一定落在两者之间。
- 未标定驱动电压到声压，所以没有16 V对应的绝对声压、作用力、膜位移或手感预测。

## 3. 传播与相位约定

对目标点m、换能器n，传播矩阵为：

```text
H[m,n] = D(theta) * exp(+j*k*r[m,n]) / r[m,n]
p = H * w
w[n] = exp(j*phi[n]), |w[n]| = 1
k = 2*pi*f/c
```

各向同性模型取D=1；假设均匀活塞取D=2*J1(u)/u、u=k*a*sin(theta)，u=0时D=1。
这里J1是一阶第一类贝塞尔函数，a为假设的有效活塞半径。
相位符号沿用仓库约定，单焦点取phi=-k*r。对照已有 `focus_phases` 的量化相位完全一致。

每种模型都以该模型在(0,0,50) mm中心单焦点的连续相位相干幅值作为唯一基准，
不对各个图案单独归一化。两模型的基准绝对值不同，所以跨行比较表示各自单焦点的比例，不能作绝对声压比较。

## 4. 优化方法

用多起点、等幅仅相位的局部优化。求解器是L-BFGS-B（Limited-memory Broyden–Fletcher–Goldfarb–Shanno with Bounds，有限内存拟牛顿优化方法），使用解析梯度。

目标函数同时考虑：

1. 指定目标点的幅值接近设定目标g。
2. 距图形至少6 mm的区域，其平均声压平方及强峰受到惩罚。
3. 用平滑最大值惩罚，避免少数强峰被平均值掩盖。

```text
q = |H_dark*w|^2 / g^2
J = mean((|H_target*w|/g - 1)^2)
  + 0.15 * mean(q + q^2)
  + 0.15/8 * log(mean(exp(8*q)))
```

最后一项使用稳定的对数求和计算，避免溢出。6个确定性起点，随机种子20261030，每次最多350步，选择目标函数最小的结果；保存全部收敛记录，不宣称全局最优。

单点使用解析聚焦解作为基准；双点位于x=±10 mm；四点在半径15 mm圆周、旋转45°的位置；八点与64个圆环控制点都在半径20 mm圆周。
双点、四点、八点、圆环的g分别人为设为0.60、0.42、0.28、0.23，是演示优化目标，不是理论最大能力。
因此不同图形的幅值递减不能当作已证明的硬件极限；仍可进一步扫描目标幅值、目标权重与图案尺寸。

## 5. 运行

从仓库根目录运行：

```powershell
python -m pip install -r experiments/static_field/requirements.txt
python -m unittest experiments.static_field.test_reference -v
python -m experiments.static_field.reference --out .runtime/static-field-20261030-peak
python -m experiments.static_field.validate_results .runtime/static-field-20261030-peak
```

数值计算限制为单线程以减少小矩阵调度开销，图像写入被忽略的`.runtime/`。脚本运行时间不是板端求解时间。

输出包含：

- `comparison.png`：五种场景、两种模型，共用0～1色标。青色十字及虚线只是目标位置标记，不是计算声场。
- `profiles.png`：圆周幅值、中心截面及目标与杂散峰比较。
- `report.md`、`results.json`：参数、量化前后指标、每次收敛记录、软件版本和参考源码哈希。
- `*_field.npz`：完整二维幅值、目标坐标和相位数组。
- `*_phases.json`：每个场景的64路相位。明确标记仅模拟、未应用实际校准、不可直接用于硬件。
- `validation.json`：0.25 mm细网格、1440个圆周角度，以及同一相位表不重新求解时跨传播模型的结果。

## 6. 本轮结果

下表来自2026-10-30带强峰惩罚的最终运行，均已量化为64档。单位是各模型中心理想单焦点幅值的比例。
杂散峰指±45 mm工作平面内、距目标点或圆周至少6 mm处的最大值；此排除带不是实际焦斑宽度。

| 模型 | 图形 | 目标平均幅值 | 目标最小/最大 | 杂散峰 |
|---|---|---:|---:|---:|
| 各向同性 | 单点 | 0.999 | 1.000 | 0.324 |
| 各向同性 | 双点 | 0.598 | 0.994 | 0.262 |
| 各向同性 | 四点 | 0.414 | 0.999 | 0.229 |
| 各向同性 | 八点 | 0.277 | 0.988 | 0.151 |
| 各向同性 | 圆环 | 0.209 | 0.709 | 0.164 |
| 假设10 mm活塞 | 单点 | 0.999 | 1.000 | 0.334 |
| 假设10 mm活塞 | 双点 | 0.599 | 1.000 | 0.369 |
| 假设10 mm活塞 | 四点 | 0.419 | 1.000 | 0.257 |
| 假设10 mm活塞 | 八点 | 0.284 | 0.981 | 0.227 |
| 假设10 mm活塞 | 圆环 | 0.237 | 0.949 | 0.191 |

双点、四点得到可区分的同时声压峰。圆环得到连续的近圆周幅值分布，但仍有杂散峰及厚度，不能称为清晰的真实触觉图形。
各向同性圆环的最小/最大仅0.709，说明圆周仍不够均匀；假设活塞模型改善，但不应单独选择更漂亮的模型作为真实结果。
这轮所有最终选中的优化解均报告收敛；全部场景量化前后目标平均幅值的绝对差小于0.0023。
首次仅有平均背景惩罚的试验保留于`.runtime/static-field-20261030/`，不作为当前源码重跑结果。

## 7. 验证和解释边界

6项数值测试通过：与现有单点相位对照、单点相干上界和量化误差界、解析梯度的有限差分核验、活塞轴向/零半径极限、相干相消与整体相位不变性、双点优化改进、非法几何拒绝（部分合并于同一测试）。

训练背景网格为2.5 mm；初次评估使用0.5 mm网格和720个错开训练角度的圆周点，再独立细化到0.25 mm/1440角度。
细化后全部场景杂散峰相对原评估的最大绝对变化为0.006981；圆环杂散峰分别为0.163854（各向同性）和0.196336（假设活塞）。上表为0.5 mm网格的原始结果，精细值保存在`validation.json`。
同一套圆环相位跨模型、不重新优化时：各向同性设计在活塞模型下的圆周最小/最大从0.709降至0.552；活塞设计在各向同性模型下从0.949降至0.762，后者杂散峰达到目标平均幅值的0.968。
这说明真实指向性失配可能明显影响图形质量，不能仅选一种理想模型就承诺实物结果。
检查的是二维指定平面，不保证三维其它位置没有强峰。收敛或漂亮图像都不能替代声学实测。
没有模拟薄膜张力、反射、耦合、谐波和人体感知；相对声压幅值不是能量百分比、触觉强度或膜位移。

## 8. 后续板端路径

先用本参考模型验证双点/四点，再建立可解释的图案强度与杂散约束。若转向板端，可先增加固定相位表装载、回读和原子切换；必须叠加正确的现有实测校准修正，核对通道顺序和相位符号。
完整求解器尚未硬件化。此处浮点优化算法不能原样视为板端逻辑；还需定点精度、迭代策略、存储带宽、资源和时序验证。
固定几何可预存传播矩阵；改变高度、位置或尺寸时需更新它。64个圆周控制点不等于64个独立可辨认焦点。
