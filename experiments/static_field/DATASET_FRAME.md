# 内置压力样本的单帧静态声场实验

2026-10-30。仅离线模拟，没有连接硬件，也没有改动上位机回放或发射控制。

## 1. 数据来源

复用上位机 `desktop_app.egopressure.load_sequence(sample_path())`，直接读取已内置的 `p_001_press_palm_low_x5_right.npz`。
在手部与压力同时有效的帧中选择总接触力最大的一帧，即第325帧、10.8秒，与现有回放默认展示帧一致。
原始峰值23.0836千帕、总接触力18.2221牛顿。这是传感器接触测量，不是阵列声压。
源文件与脚本哈希保存在输出 `results.json`。

## 2. 简化与坐标映射

对大于1千帕的网格进行四邻接连通区域提取，按区域内压力值总和保留最大的两个区域。
这两个区域占原帧压力值总和的95.435%，占阈值以上压力值总和的99.150%。这是原数据贡献比例，不是形状相似度或声学复现率。
每个区域用压力加权质心与协方差构造一个椭圆高斯分布，保留相对积分权重；丢弃细小区域及每个区域内部的多个局部峰。

沿用回放页面的240×137.5毫米传感器显示范围，横向不镜像、纵向与显示坐标一致。以阈值接触区包围框中心为原点，等比缩放0.474359倍，使最长跨度成为40毫米。
三个面板使用同一映射坐标，原图只做位置映射、取可见范围，压力数值不改变。这里是演示映射，不是对真实用户手掌的空间标定。
接触力仍使用数据集1.25毫米单元面积换算，不能用显示纹理尺寸重新换算力。

两个映射后的区域中心约为(12.10,5.84)毫米和(-11.74,-5.69)毫米。该帧原始接触区达到传感器边缘，灰色部分表示范围外无数据。
完整高斯目标会延伸到观测支持域之外，属于简化设计的外推，不是补全了真实压力。

## 3. 声学目标与算法

目标声压幅值定义为 `0.35 × sqrt(两个高斯分布之和 / 本帧密度峰值)`，相对基准为各传播模型在50毫米处的中心单焦点理想幅值。
这是保留相对强弱的一种启发式编码，不是接触压力、辐射力与超声声压之间的标定关系；本帧峰值归一化也不能直接用于动态序列，否则会丢失跨帧强弱变化。

使用8×8阵列、10.3毫米间距、50毫米平面、40千赫、343米/秒声速；64通道均为固定单位幅度，仅优化相位并量化到64档。
在2毫米网格拟合非均匀目标，目标峰值的15%以上定义为拟合区，低于8%定义为背景，其间留作过渡带。
目标函数为幅值拟合误差，加背景声压平方、四次方和强峰惩罚；10个固定随机种子的起点、每次最多500步局部优化。全部相位同时输出，不做扫描时间平均。
分别使用各向同性模型和假设10毫米均匀活塞指向性模型求解，后者未经真实器件指向性标定。

## 4. 本轮结果

以下幅值均相对于各模型的中心单焦点；并非千帕。

| 模型 | 区域1中心幅值 | 区域2中心幅值 | 背景最高幅值 | 拟合区均方根误差/目标峰值 |
|---|---:|---:|---:|---:|
| 简化目标 | 0.3501 | 0.3470 | — | — |
| 各向同性模拟 | 0.3559 | 0.3528 | 0.1475 | 6.46% |
| 假设活塞模拟 | 0.3807 | 0.3701 | 0.1965 | 6.95% |

背景峰取±40毫米平面内、目标低于峰值8%的区域。误差仅对简化后的目标计算，不是原始压力图的复现误差，更不是人体感知准确率。
两个主要区域可以表达，但宽度、形状仍失真，周围有明显杂散声场。两个局部优化的最优候选都报告收敛，不表示全局最优。
原始左侧受压区域包含两个局部峰，简化后合并成一个区域，不能宣称原图细节已经重现。

## 5. 验证与复现

```powershell
python -m unittest experiments.static_field.test_dataset_frame -v
python -m experiments.static_field.dataset_frame --out .runtime/dataset-static-frame-20261030
```

4项检查通过：非均匀目标梯度对有限差分；左右上下方向、相对权重和等比缩放；高斯积分权重；无接触帧拒绝生成目标。
0.5毫米独立网格评估，未进行本轮网格收敛研究或硬件测量。

结果在仓库 `.runtime/dataset-static-frame-20261030/`：两张中文三联图、原始压力和数值场数组、模拟相位及结果记录。
没有添加真实校准修正、阵列个体误差、反射、膜耦合或移位驱动时序误差；相位表不是可直接下发的设备配置。

## 6. 下一步

若要保留更多原图细节，应比较两个区域与3～4个局部压力峰的表示，并在同一声学资源下比较杂散和强度。
动态序列需使用固定强度标尺、稳定的区域身份与时序平滑，并明确无接触和缺失数据的处理。
真实压力分布和触觉感受仍需声学标定及实验，不从这幅模拟图推断。
